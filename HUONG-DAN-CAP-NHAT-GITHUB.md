# Cập nhật GitHub Pages

1. Sao lưu repository hiện tại.
2. Xóa toàn bộ file website cũ trong nhánh đang deploy (giữ thư mục `.git` nếu dùng Git trên máy).
3. Chép **toàn bộ file bên trong thư mục này** vào thư mục gốc repository.
4. Commit và push.
5. Chờ GitHub Pages deploy xong rồi mở trang bằng cửa sổ ẩn danh hoặc nhấn `Ctrl + F5`.

Không chép thư mục này như một thư mục con. File `index.html` phải nằm ngay ở root của repository.
